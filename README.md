# Dwingul_Dwingul

AI를 활용해서 작은 프로젝트들을 기획하고, 디자인하고, 개발합니다.

생각난 아이디어를 빠르게 구현하고,  
가볍게 배포해보고,  
재밌게 실험하며 기록하는 공간입니다.

여러 개의 웹/앱 프로젝트를 하나의 모노레포로 관리하며,  
각 프로젝트는 `projects/` 아래에서 독립적으로 실행 · 배포됩니다.
