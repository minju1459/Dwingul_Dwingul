# Dwingul_Dwingul

AI를 활용해서 뒹굴 뒹굴 프로젝트를 개발합니다.

여러 개의 작은 웹/앱 프로젝트를 한 레포에 모아두는 모노레포 구조입니다.
각 프로젝트는 `projects/` 아래에 독립적으로 들어가며, 그 자체로 실행/설치/배포가 완결됩니다.

## 구조

```
.
├── projects/         # 개별 프로젝트
│   └── 01-starter/   # Next.js + TypeScript (첫 프로젝트)
└── README.md         # 이 파일 (프로젝트 인덱스)
```

## 프로젝트 목록

| # | 이름 | 스택 | 설명 |
|---|------|------|------|
| 01 | [starter](projects/01-starter/) | Next.js + TypeScript | 첫 스캐폴드 (주제 미정) |

## 새 프로젝트 추가하기

1. `projects/NN-이름/` 폴더로 추가
2. 폴더 안에 README.md (실행법 포함) 작성
3. 위 표에 한 줄 추가
