# 나고먐미인데 (Nagomyammi-Inde)

> **타입**: 데스크탑 앱 (macOS · Electron) — 웹사이트 아님

내 맥북 데스크탑 위를 산책하는 작은 고양이.
모든 앱 위에 떠 있지만 클릭은 그대로 아래 앱으로 통과되어서 작업에 방해되지 않음.
가끔 멈춰서 정면을 보고, 걷는 중에도 눈을 깜빡임.

## 실행하기

### 1. 의존성 설치 (최초 1회)

```bash
npm install
```

→ Electron이 다운로드됩니다 (약 80MB).

### 2. 스프라이트 이미지 넣기

`assets/` 폴더에 다음 PNG 3장을 직접 저장:

| 파일 | 내용 |
|------|------|
| `assets/cat-walk.png` | 걷는 모습 8프레임 (눈 뜬 상태, 4열×2행) |
| `assets/cat-walk-blink.png` | 걷는 모습 8프레임 (눈 감은 상태, 4열×2행) |
| `assets/cat-idle.png` | 정면 보고 멈춤 8프레임 (4열×2행) |

### 3. 실행

```bash
npm start
```

→ 화면 하단에 고양이가 등장해서 좌우로 산책 시작.

## 종료하기

- Dock의 나고먐미인데 아이콘 우클릭 → **종료**
- 또는 터미널에서 `Ctrl+C`

## 동작

- **걷기**: 화면 하단을 좌우로 산책 (좌측 갈 때 자동 좌우 반전)
- **눈 깜빡임 (걷는 중)**: 2.5~5.5초마다 잠깐 (160ms) 눈 감은 스프라이트로 교체
- **멈춤**: 가끔 멈춰서 정면을 보며 가만히 있음 (3~7초)
- **눈 깜빡임 (멈춤 중)**: 1.5~3.5초마다 잠깐 (임시 — opacity 트릭, 정면 눈 감은 스프라이트 추가 시 진짜 깜빡임으로 교체)
- **방향 전환**: 일정 확률로 가던 방향 바꿈
- **경계**: 화면 좌우 끝에 닿으면 자동 회전

## 알려진 한계

- Dock 위치를 시스템에서 정확히 감지하지 않고 화면 하단에 고정. macOS Dock이 좌·우에 있거나 자동 숨김 상태면 위치가 어색할 수 있음.
- 멀티 모니터 시 주 디스플레이에만 표시됨.
- 멈춤 상태 깜빡임은 임시 (opacity 페이드). 진짜 깜빡임은 "정면 눈 감은" 스프라이트가 추가로 필요.

## 구조

```
.
├── main.js         # Electron 메인 프로세스 — 투명/최상단/클릭통과 윈도우 생성
├── index.html      # 렌더러 진입점
├── styles.css      # 고양이 스프라이트 위치/모드별 이미지/깜빡임 클래스
├── renderer.js     # 행동 로직 (걷기, 멈춤, 깜빡임 타이밍)
├── package.json
└── assets/         # 스프라이트 PNG (사용자가 채움)
```

## 데스크탑 앱인 이유

기존 03번까지는 모두 브라우저에서 도는 웹사이트. 이건 진짜 macOS 데스크탑 위에 떠 있어야 해서 네이티브에 가까운 환경이 필요함 (투명 윈도우, 모든 앱 위 표시, 클릭 통과). 그래서 Electron으로 작성된 데스크탑 앱.
