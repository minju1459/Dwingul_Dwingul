# 스프라이트

이 폴더에 다음 PNG 3장을 넣어주세요:

| 파일 | 내용 | 그리드 |
|------|------|--------|
| `cat-walk.png` | 걷는 모습 — 눈 뜬 8프레임 | 4열 × 2행 |
| `cat-walk-blink.png` | 걷는 모습 — 눈 감은 8프레임 (걷는 중 깜빡임용) | 4열 × 2행 |
| `cat-idle.png` | 정면 보고 멈춤 8프레임 (눈 뜬) | 4열 × 2행 |

## 형식

- PNG, 배경 투명
- 각 프레임 크기 동일
- 그리드 칸에 정확히 정렬 (코드에서 4×2 가정)

## 왼쪽 걷기

별도 파일 불필요 — CSS `transform: scaleX(-1)`로 자동 좌우 반전.

## (선택) 멈춤 상태 깜빡임 개선

현재는 멈춤 중일 때 잠깐 투명도가 낮아지는 임시 효과로 깜빡임을 흉내냅니다.
**정면 눈 감은 8프레임** 시트 (`cat-idle-blink.png`)를 추가로 주시면
걷는 중 깜빡임과 동일한 방식으로 진짜 깜빡임 처리로 교체 가능합니다.
